# Release Binaries Directory

This directory is designated for compiled distributables and executable installers generated by build scripts.

When you run:
```bash
npm run electron:build
```

The compiled standalone desktop installer file (`Grocery POS & Inventory Software Setup.exe`) will be generated inside this directory.

*Note: Build outputs and binary `.exe` files are ignored by git (see `.gitignore`) to prevent bloating the public code repository.*
